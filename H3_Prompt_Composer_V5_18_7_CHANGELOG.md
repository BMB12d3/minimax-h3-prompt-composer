# H3 Prompt Composer V5.18.7

V5.18.7 is a focused prompt-language and AI-import reliability release. It preserves the V5.18.6 interface, reference-routing model, and output section structure while correcting edge cases found during a guide-alignment audit.

## Prompt construction

- Camera composition now identifies the framed Subject explicitly. Start and end framing no longer allow a placement phrase such as “positioned on the left third” to attach grammatically to the camera.
- Camera endpoint composition remains distinct from camera viewpoint and angle.
- Timed-dialogue speaker IDs are assigned from the chronological order of actual vocal events, including dialogue linked to Timed Action Beats.
- Dialogue-delivery normalization now produces grammatical phrases such as “in an urgent, hushed voice,” “in an emotional whisper,” and “in a breathless and frightened voice.”
- First-appearance descriptions use general noun-phrase handling instead of a limited subject-noun whitelist. Creatures, vehicles, props, and other valid subjects receive articles consistently.
- All-capital Environment names retain their supplied capitalization instead of changing `JUNGLE CLEARING` to `jUNGLE CLEARING`.
- Generic Picture roles now choose the correct indefinite article, including “an edited keyframe.”
- Automatic summaries say that a video “contains N shots,” avoiding ambiguity with the filmmaking term “two-shot” and incorrect forms such as “a 8-shot sequence.”
- A custom summary’s bracketed task prefix is removed when it duplicates the prefix generated by the Composer.

## AI Project Setup

- Reorganized the copied AI instructions around prose ownership and concise field budgets.
- Camera objects are explicitly authoritative for framing, viewpoint, angle, composition, movement, optics, focus, stabilization, and ending frame. The AI is told not to repeat those instructions in opening state, action, Timed Beats, or summary.
- Added explicit guidance for complete Subject noun phrases, grammatical dialogue-delivery phrases, exact capitalization, and prefix-free custom summaries.
- Consolidated Environment routing into one authoritative section and shortened repeated filename/routing guidance.
- The default copied instruction package was reduced from approximately 1,771 words to approximately 1,302 words while retaining the schema example and supported value lists.

## Import validation

- Added schema-wide object, array, string, number, Boolean, and enum checks for project data, assets, Generations, Shots, camera settings, Timed Beats, dialogue, and on-screen text.
- Unknown camera enum values are reported instead of being silently discarded.
- Invalid object values are rejected before they can become `[object Object]` in the Composer.
- Null or malformed Environment Picture entries produce readable validation errors instead of crashing import preview.
- Import preview safely handles malformed Generation entries and non-object top-level JSON values.

## Compatibility

- V5.18.7 uses a new autosave and backup key and imports V5.18.6 local state on first launch.
- The six Ref2VA sections and three base-mode fields are unchanged.
- T2VA, I2VA, FL2VA, L2VA, and Ref2VA headers remain unchanged.
- Existing V5.18.6 projects migrate without changing reference labels, Environment routing, camera choices, or media bindings.
- The V5.18.6 full and illustrated user guides remain current because V5.18.7 does not change the user-facing workflow. This changelog documents the prompt-language and import-validation differences.
